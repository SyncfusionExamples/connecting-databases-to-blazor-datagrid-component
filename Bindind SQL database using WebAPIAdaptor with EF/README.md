# Blazor DataGrid SQL Server connectivity using Entity Framework and WebAPI Adaptor

A project that enables data binding and CRUD action handling in the Syncfusion Blazor DataGrid to a SQL Server using Entity Framework and WebAPI Adaptor feature.

## Prerequisites
1. .NET SDK 8.0 or 9.0
2. Visual Studio 2022 or Visual Studio Code

## Steps to run the sample

1. Download and open the BlazorApp.sln project in Visual Studio 2022.

2. Open SQL Server Object Explorer and create the table using the CreateTable query. Also, insert data using the DataSource query.

3. Update and verify the Server and Database names in the connection string values in both appsettings.json and OrdersDetailsContext.cs.

4. Run the application.
